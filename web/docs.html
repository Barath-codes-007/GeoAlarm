Getting started

  1. Open GeoAlarm and follow the short introduction. It explains each permission before Android asks for it.
  2. Choose a destination: search for a place, tap the map, or use your current location.
  3. Pick a warning distance and an alarm sound, then select Create GeoAlarm.
  4. Keep the persistent “GeoAlarm is monitoring your destination” notification visible. It is what lets Android keep the app running while your screen is off.

Permissions

GeoAlarm asks only for what it uses, one at a time, with an explanation first.

PermissionWhy GeoAlarm needs it
Precise locationTo measure how far you are from the destination. Approximate location is not accurate enough to decide arrival.
Location “all the time” (Android 10+)Recommended. It lets monitoring restart after a reboot or after Android stops the app. Without it, alarms still work when you start them while the app is visible.
Notifications (Android 13+)To show the warning, the alarm and the monitoring notification.
Foreground service (location)To keep watching your location while the app is closed.
Full-screen notificationsTo show the alarm screen over the lock screen. On Android 14+ you may need to allow this in system settings.
Run at startupTo resume active alarms after the phone restarts.
Vibrate, keep device awakeTo vibrate and to keep the alarm sound playing while the screen is off.
InternetOnly for map tiles and place search. Distance monitoring does not use the internet.

GeoAlarm does not request storage access (custom audio uses Android's file picker), exact-alarm permission, or battery-optimization exemption.

Warning distance and arrival radius

The warning distance (500, 250, 100 m, at destination, or custom) is when you get the heads-up notification. It fires once per alarm. The arrival radius (50, 100 or 200 m) is how close counts as “arrived”. If the warning distance is not larger than the arrival radius, GeoAlarm skips the separate warning and goes straight to the alarm.

Alarm states: CREATED → ACTIVE → WARNING_TRIGGERED → DESTINATION_REACHED → COMPLETED, or ACTIVE → CANCELLED. An alarm can also be PAUSED and resumed.

How GeoAlarm avoids false alarms

  • Readings with a large accuracy circle are ignored for warning and arrival decisions.
  • Two good readings inside the zone are needed in a row. A reading just outside the zone does not reset the count.
  • Sudden impossible jumps are discarded, and stale readings are ignored.
  • If you move fast and readings are far apart, GeoAlarm checks whether the line between two readings crossed the zone.
  • The active alarm screen shows GPS status, accuracy, distance and the time of the last update.

Android background limits

No app can promise to run in the background on every phone. Android and phone makers may limit background work to save battery. GeoAlarm uses the mechanism Android recommends (a foreground service with a visible notification), but some devices still stop apps aggressively.
  • Grant location “all the time” when the app suggests it.
  • Do not swipe the app away from a “force stop” menu: force-stopping an app cancels its service until you open it again.
  • If alarms stop after the screen has been off for a long time, set GeoAlarm's battery usage to Unrestricted (or Not optimized) for this app only. There is no need to turn off battery saving for the whole phone.
  • Some manufacturers add extra “auto-start” or “protected app” lists. The community site dontkillmyapp.com lists steps per brand.
  • After a reboot, GeoAlarm resumes monitoring only if Android allows it. Otherwise it shows a notification asking you to open the app.

Alarm audio

Choose the phone's default ringtone, an audio file from your device, the default notification sound, vibration only, or a silent notification. Custom audio uses Android's system file picker, so no storage permission is needed. If the file is deleted or cannot be played, GeoAlarm plays the default ringtone instead and never crashes. The alarm plays on the alarm volume stream; if that volume is zero, GeoAlarm vibrates and tells you.

Offline use

After an alarm is created, distance monitoring uses only GPS and needs no internet. Map tiles and place search do need a connection, although recently viewed map areas may be cached by the map library.

Build from source

You need JDK 17 and the Android SDK (Android Studio installs both).

git clone <your repository>
cd GeoAlarm/android
./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk

Map and search providers are configured in android/local.properties; the repository's docs/map-provider.md explains the options and each provider's usage policy. A debug APK is for testing, not a production release.
